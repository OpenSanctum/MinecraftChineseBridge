# ChineseBridge｜Minecraft 中文語系橋接模組

有些 Minecraft 模組和資源包只支援一種中文。切換成「簡體中文」、「中文（台灣）」或「中文（香港）」後，文字可能變回英文或根本沒有翻譯。

ChineseBridge 會自動找到現有的中文翻譯，補齊其他尚未支援的中文語系，讓不同地區的中文玩家都能正常閱讀。

## 功能特色

- 自動掃描已安裝模組與資源包中的中文翻譯
- 支援簡體中文 `zh_cn`、中文（台灣）`zh_tw`、中文（香港）`zh_hk`
- 只要其中一種中文存在，就會補齊缺少的其他中文語系
- 自動建立並載入中文補充資源包
- 原本已有對應中文語系時，會保留作者提供的翻譯
- 不會修改原始模組或資源包
- 模組與資源包沒有變更時會快速略過，不必每次重新翻譯
- 只需安裝在用戶端，伺服器不需要安裝

## 支援版本

| Minecraft 系列 | Fabric | Forge | NeoForge |
| --- | :---: | :---: | :---: |
| 1.20.x | ✅ | ✅ | ✅ |
| 1.21.x | ✅ | ✅ | ✅ |

如果某個 Minecraft 版本沒有推出對應的模組載入器，就無法使用該載入器版本。

## 下載與安裝

1. 前往 [Releases 下載頁面](https://github.com/OpenSanctum/MinecraftChineseBridge/releases)。
2. 選擇你的 Minecraft 系列，例如 `1.20.x`。
3. 按照載入器下載檔名中帶有 `fabric`、`forge` 或 `neoforge` 的 JAR。
4. 把下載的 JAR 放入 Minecraft 的 `mods` 資料夾。
5. 啟動遊戲，選擇你想使用的簡體中文、中文（台灣）或中文（香港）。

例如，Minecraft 1.20.x 使用 Forge，請下載：

`TChineseB-forge-1.20.x-009.jar`

> 請勿把 TChineseB 的 JAR 放進 `resourcepacks` 資料夾。

## 第一次啟動

第一次進入遊戲時，TChineseB 會掃描目前安裝的模組與資源包，並補齊缺少的中文語系。模組較多時可能需要稍等一下。

完成後，遊戲的資源包列表會出現帶有專屬圖示的：

`TChineseB-遊戲版本.zip`

這個資源包第一次會自動啟用並放在最高優先順序。之後如果你自行停用或調整順序，TChineseB 會保留你的選擇。

新增、更新或移除模組與資源包後，翻譯包也會自動更新。如果翻譯包被刪除，下次啟動時會重新建立。

## 補充方式

- 只有簡體中文時：補上中文（台灣）與中文（香港）
- 只有中文（台灣）時：補上簡體中文與中文（香港）
- 只有中文（香港）時：補上簡體中文與中文（台灣）
- 已經存在的中文語系：保留原作者內容，不會覆蓋

中文（台灣）會套用台灣常用詞與 Minecraft 慣用譯名。其他語系則會轉換成對應的簡體或繁體字詞。不同模組可能使用自己的專有名詞，因此少數文字仍可能需要人工調整。

## 常見問題

### 為什麼第一次啟動比較久？

第一次需要讀取所有模組與資源包並建立翻譯。完成後，只要安裝內容沒有改變，後續啟動就會直接略過重複工作。

### 為什麼有些內容沒有被翻譯？

如果原模組完全沒有提供中文，ChineseBridge 就沒有可補充的來源。少數模組也可能使用一般語系檔以外的方式顯示文字。

### 可以停用自動產生的資源包嗎？

可以。第一次載入後，你可以像管理一般資源包一樣停用或調整順序，ChineseBridge 不會擅自改回去。

### 伺服器也要安裝嗎？

不用。ChineseBridge 是用戶端模組，只要玩家自己安裝即可。
